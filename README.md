# distance_calculator.py

##Description
This program converts kilometers into miles

##How to run the program
1. Open the code in VS, Replit, or Programiz.
2. Run the program
3. Enter the distance in kilometers
4. Check the results in the screen
5. Answer yes if interested to convert more kilometers into miles
6. Enter the distance in kilometers
7. Check the results in the screen

##Input needed
1.distance in kilometers

##Sample
Enter distance in kilometers: 5
Distance in miles: 3.061855
Do you want to convert another distance? (yes/no): yes
Enter distance in kilometers: 40
Distance in miles:  24.49484
